Știri analizate

Cum influențează semnalele

Fiecare știre primește impact 0–100, bias și instrumente relevante. La salvarea unui semnal, scorul adaptiv este penalizat cu 7 puncte pentru risc mediu și 14 puncte pentru risc ridicat.

Titlurile sunt preluate fără chei API din fluxurile oficiale Federal Reserve și U.S. Bureau of Labor Statistics. Dacă FMP răspunde HTTP 402, este oprit automat pentru sesiunea serverului, iar fluxurile oficiale continuă. Fără calendar anticipat se aplică automat un risc de siguranță, nu risc zero.
